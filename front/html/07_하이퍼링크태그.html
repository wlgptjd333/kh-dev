하이퍼 링크 태그

다른 웹페이지, 같은 사이트의 파일, 또는 현재 페이지의 특정 위치로 이동할 때 사용하는 태그입니다.

1. 외부 사이트로 이동 (target 속성)

  • 구글로 이동 (현재 창: _self)
  • 네이버로 이동 (새 탭: _blank)

2. 내 프로젝트 안의 다른 HTML 파일로 이동 (내부 링크)

  • 01_글자관련태그 페이지로 이동
  • 03_표관련태그 페이지로 이동
  • 05_이미지관련태그 페이지로 이동
  • 06_미디어관련태그 페이지로 이동

3. 이미지를 클릭하면 이동하는 이미지 링크

이미지(img)를 a 태그로 감싸면 클릭할 수 있는 버튼/링크가 됩니다.

4. 페이지 내 특정 위치로 이동 (책갈피 / 앵커)
